# Rubber Duck Detector - Frontend

This is the frontend for the Rubber Duck Detector application.

## Features
- Upload images for rubber duck detection
- View detection results with confidence scores
- Download labeled images
- Responsive design

## Deployment
This frontend is designed to be deployed on Vercel and connects to the backend API deployed on Render.

## Setup
Update the `API_URL` in `index.html` with your Render API URL after deployment.
